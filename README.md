# Teams Background Generator

Generative Intercept (Fritz) triangle-keyline tool for Microsoft Teams call backgrounds.

A right-angle Fritz triangle is spiralled along a wandering 3D Bézier path — multi-string
colour, spiral / wander / 3D-tilt controls, an organic logo keep-out zone, and a curated
**Randomize** that stays inside the brand parameters. Exports a 4K PNG with the Intercept
lockup baked into the top-left.

**Live:** https://interceptlabs.github.io/teams_background_generator/

Single self-contained `index.html` — no build, no dependencies. Open it and drag the sliders.
